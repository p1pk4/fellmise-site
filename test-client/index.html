  1. Распакуй архив в любую папку.
  2. Запусти Fellmise.exe (двойной клик).
  3. Откроется окно игры — подключение к тестовому серверу идёт автоматически.
Если Windows покажет предупреждение SmartScreen — нажми «Подробнее» → «Всё равно запустить» (обычное дело для нового приложения без платной подписи, не вирус).

Сервер работает в интернете (test.fellmise.com:7770) — нужен только интернет, локальная сеть не требуется. Если игра просит обновиться — версия на сервере поменялась, скачай свежий latest.zip с этой страницы.
